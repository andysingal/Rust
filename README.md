-[runagent](https://github.com/runagent-dev/runagent)
RunAgent is a revolutionary platform that solves the language barrier problem in AI development. Write your AI agents once in Python using any framework, then access them natively from Rust, JavaScript, Go, or any other language(Python itself) through our comprehensive SDKs. 

- [SurrealDB](https://github.com/surrealdb/surrealdb)

SurrealDB is a single database that combines relational, document, graph, and time-series models, built in Rust for performance.

- Multi-model support with tables, documents, graphs, and time-series in one query.
- Built-in permissions and row-level security for access control.
- Client libraries for JavaScript, Python, .NET, PHP, and more.
- Deployable via Docker or as a standalone binary.
